# 🌤️ Berlin Real-Time Weather Data Pipeline

## 📋 Project Overview
An automated data pipeline that fetches
real-time hourly weather data for Berlin
using Open-Meteo API, performs data
cleaning, statistical analysis, and
exports results to CSV and Excel formats.

## 🛠️ Tools & Technologies
- **Python** - Core programming
- **Pandas** - Data manipulation
- **Requests** - API data fetching
- **OpenPyXL** - Excel export
- **Open-Meteo API** - Free weather API

## 📊 Features
- ✅ Fetches 7 days hourly weather data
- ✅ 6 weather metrics collected
- ✅ Complete data cleaning & validation
- ✅ Statistical analysis & insights
- ✅ Business insights & alerts
- ✅ CSV & Excel export

## 📈 Weather Metrics Collected
| Metric | Description |
|--------|-------------|
| temperature_c | Actual temperature |
| feels_like_c | Feels like temperature |
| windspeed_kmh | Wind speed |
| humidity_pct | Humidity percentage |
| rain_chance_pct | Rain probability |
| weather_condition | Weather description |

## 🔍 Analysis Performed
1. Overall weekly statistics
2. Daily temperature summary
3. Hottest & coldest hours
4. Windiest hours
5. Most humid hours
6. Rain forecast alerts
7. Weather condition breakdown
8. Hourly temperature patterns

## 💡 Business Insights Generated
- Best day to go outside
- Worst day weather score
- Health alerts (humidity, wind, cold)
- Best hours today for outdoor activity
- Weekly weather summary report

## 📁 Output Files
- berlin_weather_data.csv (168 rows, 11 columns)
- berlin_daily_summary.csv (7 days summary)
- berlin_weather_report.xlsx (4 sheets)
